# צמד ברזל – אתר אימפקט לתורמים

אתר סטטי לדיווח לתורמים על פעילות צמד ברזל. לכל תורם דף אישי עם פנייה משלו; כל שאר התוכן משותף ומנוהל במקום אחד.

| דף | כתובת |
|---|---|
| סרחיו ואלין פוגל | `/sergio-alin/` |
| אלי לדרמן | `/eli-lederman/` |

> **חשוב:** GitHub Pages הוא אתר ציבורי. כל מי שיש לו את הקישור יכול לפתוח את הדף. הדפים מוגדרים כך שמנועי חיפוש לא יאנדקסו אותם, אבל זו אינה הגנה בסיסמה. אם יידרש בעתיד דף פרטי באמת, צריך אירוח עם אימות משתמשים.

---

## איפה נמצא כל דבר

```
content/
  site.yaml          ← טקסטים כלליים, מצב האתר (טיוטה/סופי), תמונת שער ותמונת סיום
  stats.yaml         ← נתוני אוקטובר, תאריך עדכון והישגים
  gallery.yaml       ← רשימת התמונות בגלריה
  testimonials.yaml  ← פידבקים
  media.yaml         ← סרטונים וכתבות
  donors/
    sergio-alin.yaml   ← פנייה אישית לסרחיו ואלין
    eli-lederman.yaml  ← פנייה אישית לאלי
    _template.yaml     ← תבנית לתורם חדש

src/assets/photos/   ← כל התמונות מהשטח
src/assets/logos/    ← לוגואים
public/              ← תמונת התצוגה המקדימה לוואטסאפ (og-image.jpg)
```

כל קובץ תוכן מכיל הסברים בעברית בראשו (שורות שמתחילות ב-`#`).

---

## עריכה דרך GitHub – העיקרון

1. נכנסים ל-Repository באתר GitHub.
2. פותחים את הקובץ הרצוי ולוחצים על סמל העיפרון (Edit).
3. משנים, ולמטה לוחצים **Commit changes**.
4. האתר נבנה ומתפרסם מחדש אוטומטית תוך 1–3 דקות.

**כללי זהב בקבצי ה-yaml:**
- לשמור על ההזחה (הרווחים בתחילת השורה) בדיוק כמו בפריטים הקיימים.
- טקסט בעברית כותבים בין מירכאות רגילות `"..."`. אם צריך מירכאות בתוך הטקסט, משתמשים ב-״ (גרשיים עבריים).
- `true` / `false` כותבים באנגלית, בלי מירכאות.
- מספרים בלי פסיקים: `15000` ולא `15,000`.

## איך להעלות תמונה חדשה

1. ב-GitHub נכנסים לתיקייה `src/assets/photos`.
2. **Add file → Upload files**, גוררים את התמונה ולוחצים **Commit changes**.
   - מומלץ שם קובץ באנגלית בלי רווחים, למשל `school-haifa-01.jpg`.
   - אפשר להעלות תמונות באיכות מלאה. האתר מקטין ומכווץ אותן אוטומטית.
3. פותחים את `content/gallery.yaml` ומוסיפים פריט (או ממלאים פריט "להשלמה" קיים):

```yaml
  - file: "school-haifa-01.jpg"
    alt: "צמד מילואימניקים משוחח עם תלמידי תיכון בכיתה"
    caption: "מפגש בתיכון בחיפה"
    approved: true
    status: published
```

- `alt` – תיאור קצר של התמונה, לנגישות. חובה.
- `approved: true` – רק אם התמונה אושרה לפרסום. **אם מופיעים בה תלמידים או קטינים – רק עם אישור מתאים.**
- להסרת תמונה: מוחקים את הפריט, או משנים ל-`status: draft`.
- סדר הפריטים בקובץ = סדר התמונות בגלריה.

**תמונת שער ותמונת סיום:** מעלים לאותה תיקייה, ובקובץ `content/site.yaml` כותבים את שם הקובץ ב-`heroImage` / `closingImage` ותיאור ב-`heroImageAlt` / `closingImageAlt`.

**תצוגה מקדימה בוואטסאפ:** מעלים תמונה בגודל 1200×630 בשם `og-image.jpg` לתיקייה `public`, ובקובץ `site.yaml` כותבים `ogImage: "og-image.jpg"`. (וואטסאפ שומר תצוגות מקדימות בזיכרון – אם הקישור כבר נשלח, ייתכן שהתמונה החדשה תופיע רק אחרי זמן מה.)

**לוגואים:** מעלים לתיקייה `src/assets/logos` בשמות `iron-pair.svg` (או ‎.png) ו-`nifgashim.svg` (או ‎.png). הם יופיעו אוטומטית בראש הדף ובתחתיתו.

## איך להוסיף פידבק

בקובץ `content/testimonials.yaml`:

```yaml
  - text: "הטקסט המלא של הפידבק, בדיוק כפי שנמסר."
    name: "שם"            # יוצג רק אם showName: true
    role: "מנהלת בית ספר בדרום"
    showName: false
    approved: true
    featured: true        # true = יופיע בין שלושת הראשונים
    status: published
```

- להשתמש **רק בציטוטים אמיתיים**.
- שם מלא מפרסמים רק עם אישור (`showName: true`). בלי אישור – מספיק תיאור כללי ב-`role`.
- שלושת הראשונים מוצגים מיד; השאר בלחיצה על "לקולות נוספים". אפשר לשנות את המספר ב-`site.yaml` (`visibleCount`).

---

## איך לשנות מספר או נתון

בקובץ `content/stats.yaml`:

1. מעדכנים את `value` (מספר בלי פסיקים) ואת `label`.
2. אחרי שהנתון אומת – משנים ל-`verified: true`. **נתון שלא אומת לא יוצג במצב סופי.**
3. מעדכנים את `updatedAt` לתאריך העדכון (`"2026-10-31"`).
4. כשאלה נתוני סיכום החודש הסופיים – משנים ל-`final: true`. עד אז יוצג באתר "נתונים ראשוניים, נכון ל-...".

להוספת כרטיס נתון נוסף – מעתיקים פריט קיים ומשנים אותו.

```yaml
    status: published
```

סרטוני יוטיוב נטענים רק כשלוחצים עליהם, כך שהם לא מאטים את האתר.

## איך ליצור דף אישי לתורם נוסף

1. בתיקייה `content/donors` פותחים את `_template.yaml` ומעתיקים את התוכן.
2. **Add file → Create new file** באותה תיקייה, ונותנים שם באנגלית בלי רווחים, למשל `david-cohen.yaml`.
3. מדביקים, ממלאים את הפנייה האישית (שימו לב ללשון יחיד/רבים) ושומרים.
4. הדף החדש יהיה בכתובת `.../david-cohen/`.

דף הבית של האתר בכוונה אינו מציג רשימת תורמים – כל תורם מקבל רק את הקישור שלו.

---

## לפני שליחת הקישור לתורמים

בקובץ `content/site.yaml` לשנות:

```yaml
mode: final
```

במצב `draft` (טיוטה) מוצגים מקומות ריקים מסומנים "להשלמה" ונתונים שטרם אומתו מסומנים. במצב `final` כל מה שלא הושלם ואושר – מוסתר לגמרי, ואזור ריק לא יופיע בכלל.

---

## איך לבדוק שהאתר התעדכן

1. ב-Repository לוחצים על הלשונית **Actions**.
2. בראש הרשימה מופיעה הריצה האחרונה:
   - 🟡 עיגול צהוב – בתהליך (1–3 דקות).
   - ✅ וי ירוק – פורסם. מרעננים את הדף (בנייד: לסגור ולפתוח מחדש).
   - ❌ איקס אדום – הייתה בעיה, והאתר הקודם נשאר באוויר. לוחצים על הריצה → **build** → פותחים את השלב **Build**. הודעת השגיאה כתובה בעברית ומציינת באיזה קובץ ובאיזה שדה הבעיה (למשל תמונה שלא נמצאה או בעיית הזחה).

## למפתחים

```bash
npm install
npm run dev      # http://localhost:4321/sergio-alin/
npm run build    # בנייה לתיקייה dist
```

Astro + TypeScript, ללא שרת וללא מסד נתונים. התוכן נטען ומאומת ב-`src/lib/content.ts`. הפרסום מוגדר ב-`.github/workflows/deploy.yml`, ונתיב הבסיס של GitHub Pages נקבע אוטומטית.
